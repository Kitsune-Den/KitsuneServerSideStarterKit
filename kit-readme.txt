Kitsune Server Side Starter Kit v{{VERSION}}
=============================================

Kitsune mods that run on the server only. Players don't install anything.

For 7 Days to Die 3.x dedicated servers. Single player works too.


Install
-------

1. Copy everything inside Mods/ into your server's Mods folder.
2. Want any of the optional mods? Copy them in too (see below).
3. Turn EAC off on the server (four of the core mods use Harmony).
   Players can keep EAC on.
4. Restart the server.

Don't want one of the mods? Delete its folder. Each mod works on its own.


What's in Mods/
---------------

KitsuneServerPerf            Server CPU fixes, plus the kperf command to see
                             which mods eat your server's time.
KitsuneFuelSaver             Forges, campfires and other fueled workstations
                             switch off when there's nothing left to do.
KitsuneTerrainFit            Terrain meets the blocks you build on it,
                             instead of dipping away around them.
KitsuneTrapXP                Trap and turret kills give the owner XP.
KitsuneZombieReach           Zombie and animal hits land closer to where
                             they actually are.
KitsunePower                 Lenient power: solar, generator and battery
                             banks each put out up to 4500W.
zz_Kitsune Vehicle Overhaul  Vehicles take less damage from cacti, bushes
                             and crashes.
KitsuneKitchen               New dishes and drinks with their own buffs,
                             and Sham Sandwiches sell to traders.

Some of these change gameplay, not just performance: Trap XP, Zombie Reach,
Power, Vehicle Overhaul and Kitchen. Read the list before you install all
of it.


What's in Optional/
-------------------

PvP/KitsunePvPExtended
    Scales player-against-player damage only, with presets from
    vanilla-light to hardcore. PvE stays vanilla. For PvP servers.

CraftingTimes-PickOne/
    Faster crafting everywhere. Install ONE of these, not several:
      KitsuneCraftingTimes_Little   25% faster
      KitsuneCraftingTimes_Medium   50% faster
      KitsuneCraftingTimes_Fast     75% faster
      KitsuneCraftingTimes_Faster   90% faster
